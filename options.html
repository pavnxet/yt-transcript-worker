Point the extension at your own yt-transcript-worker Cloudflare Worker.

2. Preferences

These apply to the popup and the in-page panel, and take effect immediately.

Show the floating button Display the Transcript button on YouTube video pages. Turn it off to keep the page clean — the popup and the keyboard shortcut still work.
Auto-download after fetching Save the transcript file automatically as soon as a fetch finishes.
Auto-fetch on video pages Open the panel and fetch the transcript whenever you land on a YouTube video.
Default export format Used by Download and by auto-download.

3. How it works

  1. The extension reads the video id from the YouTube link you give it.
  2. It POSTs youtube_url to <your-worker>/process as multipart form-data.
  3. The worker rotates its API keys and returns a timestamped transcript.
  4. You copy it, copy it with the AI note prompt, or download it as .txt, .srt or .md.

Tip: on a YouTube page, press Alt+Shift+T to open the in-page transcript panel. Rebind it at chrome://extensions/shortcuts.

4. Privacy

Your worker URL and transcript requests go only to the worker you configure — nothing is sent anywhere else. Access is granted to that one origin only, and the extension asks for no permission to read your browsing history.
